# Apex Digital – High-Performance Business Landing Page

A modern, mobile-first responsive landing page engineered for local businesses and modern digital services. Built with semantic HTML5, custom CSS3, and Bootstrap 5 with a strong focus on page speed optimization and clean UI/UX.

🔗 **Live Demo:** [https://manjeetshekhawat0609.github.io/client-landing-page/](https://manjeetshekhawat0609.github.io/client-landing-page/)

---

## 🚀 Key Features

- **Mobile-First Responsive Layout:** Seamless rendering across all screen sizes (mobile, tablet, desktop).
- **Performance Optimized:** Integrated lightweight asset pipelines, Google Fonts preconnect, and minified scripts for sub-second load times.
- **Modern UI Components:** Custom-styled hero section, interactive service cards, pricing tiers, and an accordion FAQ.
- **Client Conversion Funnel:** Clean call-to-action (CTA) buttons and integrated inquiry forms.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic Structure)
- **Styling:** CSS3, Bootstrap 5.3, Bootstrap Icons
- **Typography:** Plus Jakarta Sans (Google Fonts)
- **Deployment:** GitHub Pages

---

## ⚡ Performance Highlights

- Optimized asset loading via CDN with `preconnect` resource hints.
- Zero heavy third-party framework dependencies for lightweight DOM rendering.
- Structured modular CSS with reusable variables for scalable theme customization.
